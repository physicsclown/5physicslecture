    개념 추가

    GitHub Pages에 올리기

    1. 자료 등록을 마친 뒤 ‘GitHub 배포용 index.html 저장’을 누릅니다.
    2. 다운로드한 index.html을 저장소 최상위에 올립니다.
    3. Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다.
    4. 배포된 주소를 친구들에게 공유합니다.
    5. 자료를 바꾸면 배포 파일을 다시 만들어 GitHub에서 교체합니다.

    별도의 서버·API 키가 필요하지 않습니다. 직접 업로드한 자료가 포함된 HTML은 최대 40MB로 제한합니다.
